# E-ray MIDI 사용설명서

이 문서는 개발자가 아니라 **실제로 앱을 써보고 싶은 사용자**를 위한 안내입니다.
빌드나 코드 구조가 궁금하면 [BUILDING.md](../BUILDING.md)를 참고하세요.

---

## 1. 준비물

E-ray MIDI는 혼자서는 소리를 낼 수 없습니다. 반드시 아래 두 가지가 필요합니다.

1. **ROM 또는 사운드폰트 파일** — 재생할 엔진에 맞는 파일 (2장 참고, 저작권 때문에
   앱에 포함되어 있지 않습니다)
2. **MIDI 입력 경로** — 어디선가 MIDI 신호를 받을 방법 (3장 참고). 외부 PC가 필요
   없는 "MIDI 파일 재생"도 포함됩니다 (4장 참고).

---

## 2. 엔진별 파일 준비

앱을 처음 실행하면 화면 왼쪽 "MODE" 패널에서 재생 엔진 5개 중 하나를 고를 수
있습니다.

| 엔진 | 필요한 파일 | 넣을 위치 |
|---|---|---|
| 🎼 SC-55 | SC-55mk2 ROM 5개 | `내장저장소/Download/rom_sc55/` |
| 🎷 MT-32 | `MT32_CONTROL.ROM`, `MT32_PCM.ROM` | `내장저장소/Download/rom_munt/` |
| 🎵 SoundFont | 원하는 `.sf2` 파일 | `내장저장소/Download/soundfont/` |
| 🎛 88emu | 11개 기종(SC-55/SC-88/SC-88Pro/SC-8820/SC-8850, MT-32/CM-32L/CM-32P/CM-64) 중 고른 기종의 ROM | `내장저장소/Download/rom_gearmulator/` (하위 폴더도 OK, **파일명 무관** — 내용으로 자동 인식) |
| 🎹 S-MU2000 | `mu2000_flash.bin`(프로그램, 이름 무관) + `dump/` 폴더 안 웨이브 ROM 4개 | `내장저장소/Download/rom_mu2000/` (웨이브 ROM 4개는 **파일명이 정확히 일치**해야 함: `xv364a0.ic49`, `xv365a0.ic50`, `xw848a0.ic53`, `xw849a0.ic54`). **(선택)** LCD 문자 ROM `hd44780u_b04.bin`(4KB)을 `rom_mu2000/` 폴더에 넣으면 LCD 글자 모양이 실기와 같아지고, 없으면 내장 폰트로 표시됩니다 |

파일을 넣은 뒤 앱에서 해당 엔진을 선택하면 화면에 "ROM N/M개 확인" 또는
"없음: xxx.bin" 처럼 현재 상태가 표시됩니다. 부족한 파일이 있으면 "ROM 파일 안내"
버튼을 눌러 정확한 파일명을 다시 확인할 수 있습니다.

SoundFont 모드는 "사운드폰트 선택" 버튼으로 `.sf2` 파일 목록에서 고를 수 있고,
마지막으로 쓴 파일을 자동으로 기억합니다.

88emu 모드는 "🎹 기종: ..." 버튼을 눌러 11개 기종 중 하나를 팝업에서 고릅니다 —
각 항목 옆에 해당 ROM이 실제로 인식됐는지(✅/⚠️)가 실시간으로 표시됩니다.

> ROM/사운드폰트 파일은 저작권 보호 대상이라 각자 합법적으로 구해서 넣어야 합니다.

## 3. 연결 방식 고르기

화면 오른쪽 "LINK" 패널에서 4개 중 하나를 고릅니다. 상황에 맞게 선택하세요.

### 📡 RTP-MIDI (WiFi)
[E-RayDSB](https://github.com/Electric-ray/E-RayDSB) ESP32 기기가 만드는 WiFi
AP(핫스팟)에 안드로이드 기기를 연결한 상태에서 사용합니다. 케이블이 필요 없지만,
**엔진을 자주 전환하면 재연결까지 시간이 걸릴 수 있습니다** (알려진 이슈, 6장 참고).
가끔씩만 전환한다면 문제없이 쓸 수 있습니다.

### 🔌 USB 시리얼
ESP32와 USB-OTG 케이블로 직접 연결합니다. 가장 안정적이고 지연도 적습니다.
엔진을 자주 바꿔가며 테스트한다면 이 방식을 권장합니다.

### 🎹 USB MIDI기기
ESP32 없이, **Windows PC 등과 케이블로 직접 연결**할 때 씁니다. 이 모드를 켜면
안드로이드 폰 자체가 표준 USB MIDI 장치로 동작합니다.

1. 안드로이드 기기의 "개발자 옵션" 또는 USB 연결 설정에서 USB 연결 방식을
   **"MIDI"**로 바꿉니다 (기기마다 메뉴 위치가 다를 수 있음 — 보통 알림창의
   "이 USB를 통해 충전 중" 항목을 눌러 나오는 목록에 있습니다).
2. 케이블로 PC와 연결하면, Windows 쪽 "사운드, 비디오 및 게임 컨트롤러"에
   MIDI 장치로 인식됩니다.
3. 앱에서 "🎹 USB MIDI기기" 선택 → 원하는 재생 엔진 선택 → "연결" 버튼.
4. Windows의 MIDI 출력 프로그램(SoftMPU, DAW 등)에서 이 안드로이드 기기를
   출력 장치로 선택하면 소리가 납니다.

> USB MIDI기기 모드는 RTP-MIDI/USB 시리얼과 달리 ESP32가 필요 없습니다 — PC와
> 안드로이드를 케이블 하나로 바로 연결하는 용도입니다.

### 🎵 MIDI 파일
외부 PC나 ESP32 없이, **폰에 저장된 .mid 파일을 바로 재생**합니다. 자세한 사용법은
바로 아래 4장을 참고하세요.

## 4. MIDI 파일 재생 사용법

LINK 패널에서 "MIDI 파일"을 선택하고 재생 엔진을 고른 뒤 "연결" 버튼을 누르면,
화면 아래에 재생바가 나타납니다.

### 파일 넣기
기본 폴더는 `내장저장소/Download/midi/`입니다. 이 폴더에 `.mid`/`.midi`/`.kar`
파일을 넣어두면 자동으로 인식됩니다(하위 폴더로 앨범/장르별로 나눠둬도 되고,
재생바의 📂 버튼으로 다른 폴더를 탐색해서 그 폴더를 재생목록으로 삼을 수도
있습니다 — 마지막으로 연 폴더는 다음 실행 때도 기억됩니다).

**마지막으로 들은 곡도 기억합니다.** 엔진을 바꾸거나 앱을 껐다 켜도 1번 곡이 아니라
마지막으로 재생했던 곡이 선택된 상태로 시작합니다(곡 안의 재생 위치까지는 기억하지
않고, 그 곡이 현재 폴더에 없으면 1번 곡부터입니다).

### 재생바 버튼
| 버튼 | 동작 |
|---|---|
| 📂 | 폴더/파일 탐색 — 폴더를 고르면 그 폴더 전체가 재생목록이 됨, 파일을 직접 고르면 그 곡부터 재생 |
| ⏮ / ⏭ | 이전곡 / 다음곡 (⏮은 재생 3초가 안 지났으면 이전곡으로, 지났으면 지금 곡 처음으로) |
| ▶ / ⏸ | 재생 / 일시정지 (토글) |
| ⏹ | 정지 (처음부터 다시 재생) |
| 진행바 | 눌러서 곡 중간으로 이동(시크) 가능 |
| 🔊 슬라이더 | MIDI 파일 재생 전용 볼륨(기기 볼륨과는 별개) |
| 재생모드 버튼 | 누를 때마다 순서대로 전환: **1곡**(한 곡만 재생하고 멈춤) → **폴더 전체**(순서대로 끝까지 재생하고 멈춤) → **폴더 반복**(끝까지 가면 처음부터 다시) → **1곡 반복** |

### 블루투스(차량)·유선 이어폰 리모컨
블루투스로 차량과 연결돼 있다면, **스티어링휠이나 헤드유닛의 재생/정지/다음곡/
이전곡 버튼**으로 그대로 조작할 수 있습니다. 유선 이어폰 리모컨의 재생·일시정지/
다음곡/이전곡 버튼(싱글/더블/트리플 클릭)도 동일하게 동작합니다 — 앱을 따로
조작할 필요 없이 리모컨만으로 곡을 넘기거나 멈출 수 있습니다. 화면이 꺼져 있어도
재생/일시정지 버튼이 동작합니다. 전화가 오면 자동으로 일시정지되고, **통화가 끝나면
소리 출력을 다시 연결한 뒤 이어서 재생**합니다.

> ⚠️ 화면이 꺼지거나 앱이 완전히 백그라운드로 밀려나면 재생이 끊길 수 있습니다
> (6장 참고). 차에서 장시간 들을 때는 화면이 꺼지지 않도록 해두는 것을 권장합니다.

## 5. 기본 사용 순서

1. 재생 엔진에 맞는 ROM/사운드폰트 파일을 미리 넣어둡니다 (2장).
2. 연결 방식을 고릅니다 (3장). MIDI 파일을 바로 재생하고 싶다면 "🎵 MIDI 파일"을
   고르고 4장을 참고하세요 — 이 경우 아래 5번(외부 MIDI 소스)은 필요 없습니다.
3. 재생 엔진을 고릅니다.
4. "연결" 버튼을 누릅니다.
5. (RTP-MIDI/USB 시리얼/USB MIDI기기일 때) MIDI 소스(게임, DAW 등)에서 재생을
   시작하면 소리가 납니다. (MIDI 파일일 때) 재생바의 ▶ 버튼을 누르거나 📂로
   폴더를 고르면 바로 재생됩니다.
6. 다른 엔진/연결 방식으로 바꾸려면 먼저 "정지" 버튼을 누른 뒤 다시 고르고
   "연결"을 누릅니다.

### 화면에 표시되는 것들
- **SC-55 모드**: 실제 SC-55 LCD 화면을 그대로 재현 (파라미터 레벨미터 애니메이션 포함)
- **MT-32 모드**: 실제 MT-32 LCD의 한 줄(파트 활성 표시, Rhythm, 마스터 볼륨)을 연두색 도트
  LCD로 표시합니다.
- **SoundFont 모드**: MU2000 스타일의 **가상 LCD**를 표시합니다 — 16파트 레벨미터, 프리셋명,
  뱅크/프로그램 번호, VOL·EXP 막대, PAN 바늘, REV·CHO 표시. 기본으로는 마지막으로 소리가 난
  파트를 보여 주고, **화면을 탭하면 파트 1→16 순서로 직접 고를 수 있으며 길게 누르면 다시 자동으로
  따라갑니다.** (레벨미터는 MIDI 입력의 세기에서 계산한 값입니다.)
- **88emu 모드**: 선택한 기종의 **실제 LCD를 그대로** 표시합니다 — SC-55/SC-88 계열은
  주황 유리 LCD(악기명, 파트 번호, LEVEL/PAN/REVERB/CHORUS 숫자, 16파트 레벨미터,
  L/R 램프), SC-8850은 그래픽 LCD, MT-32/CM은 연두색 도트 화면. LCD가 없는 SC-8820은
  SoundFont와 같은 가상 LCD로 표시됩니다.
- **S-MU2000 모드**: 실제 MU2000 LCD를 표시합니다 — 위쪽에 파트 레벨미터와 음색명,
  아래쪽에 파트 번호/뱅크/악기 모양, 그리고 VOL·EXP 막대, PAN 바늘, REV·CHO·VAR
  부채꼴, KEY(노트 시프트) 숫자, XG/GS/PERFORM 표시가 나옵니다.

모든 모드에서 LCD가 화면 가운데를 가득 채웁니다(예전의 채널별 LED 표시줄은 없어졌습니다).

## 6. 알려진 이슈 / 문제 해결

**Q. RTP-MIDI로 연결했다가 다른 엔진으로 바꾸려는데 한참 안 될 때가 있어요.**
A. 알려진 미해결 이슈입니다 (ESP32 쪽 AppleMIDI 라이브러리가 세션 종료 신호를
받고도 바로 새 연결을 받아주지 않는 경우가 있음). 잠시 기다리면 자동으로
재연결되거나, 급하면 🔌 USB 시리얼이나 🎹 USB MIDI기기 모드를 대신 쓰세요.

**Q. MT-32로 특정 곡만 재생하면 소리가 안 나요.**
A. 그 곡이 SC-55(GS) 전용으로 만들어졌고, MT-32 자체 리셋으로도 못 살릴 만큼
채널 배정이 꼬여 있을 가능성이 있습니다. 같은 곡을 SC-55 모드로 먼저 틀어봐서
거기서는 정상인지 확인해보세요 — SC-55에서도 안 되면 그 곡 자체의 문제입니다.

**Q. ROM 파일을 넣었는데 계속 "없음"이라고 나와요.**
A. "ROM 파일 안내" 버튼으로 정확한 파일명과 경로를 다시 확인하세요. SC-55/MT-32/
S-MU2000은 파일명까지 정확히 일치해야 합니다(대소문자 포함). 88emu는 파일명이
아니라 내용으로 인식하므로, `rom_gearmulator/` 폴더에 넣었는데도 "없음"이면
파일 자체가 손상됐거나 다른 기종용일 가능성이 높습니다.

**Q. USB MIDI기기 모드에서 Windows는 인식하는데 소리가 안 나요.**
A. 앱에서 "연결" 버튼을 눌러 엔진을 실제로 시작시켰는지 확인하세요. Windows가
장치로 인식하는 것과 앱 안에서 엔진이 켜져 있는 것은 별개입니다 — 반드시 앱에서
연결까지 완료해야 소리가 납니다.

**Q. 전화를 받고 나서 소리가 안 나요 (블루투스).**
A. v1.9부터는 통화로 출력 경로가 바뀌어 소리 출력이 끊겨도 앱이 몇 초 안에 스스로 다시
연결하고, 통화가 끝나면 MIDI 파일 재생도 이어서 시작합니다. 그래도 소리가 돌아오지
않으면 ⏹ 후 다시 ▶를 눌러 보세요. 그래도 안 되면 블루투스를 껐다 켜서 재연결한 뒤
"정지 → 연결"을 다시 해 보세요 (기기 쪽 블루투스 상태 문제일 수 있습니다).

**Q. S-MU2000 LCD가 초록색 배경만 나오거나 글자가 이상해요.**
A. v1.9 이전 버전에서는 LCD 문자 ROM이 없어 화면이 비어 있었습니다. 최신 버전은 내장
폰트로 표시하므로 영문/숫자는 정상이고, 기호 글자 모양만 실기와 조금 다를 수 있습니다.
실기와 똑같이 보고 싶다면 `hd44780u_b04.bin`(4KB)을 `rom_mu2000/` 폴더에 넣으세요. 부팅이
끝나기 전에는 LCD가 꺼져 있을 수 있으니 몇 초 기다려 보세요.

**Q. 차량 블루투스나 유선 이어폰 리모컨 버튼이 안 먹어요.**
A. LINK가 "MIDI 파일" 모드로 연결되어 있는지 먼저 확인하세요(다른 연결
방식에서는 재생할 "곡"이라는 개념 자체가 없어서 리모컨 버튼이 할 일이
없습니다). 그래도 안 되면 블루투스를 한 번 껐다 켜서 재연결해보세요 — 차량
헤드유닛에 따라 미디어 세션을 다시 인식시켜야 할 때가 있습니다.

**Q. MIDI 파일 재생 중 화면이 꺼지거나 한참 뒤 소리가 멈춰요.**
A. 현재 구조는 포그라운드 서비스가 아니라 화면을 켜둔 상태를 전제로 재생을
유지합니다. 화면이 꺼지거나 앱이 완전히 백그라운드로 밀려나면 안드로이드가
재생 스레드를 중단시킬 수 있습니다 — 차에서 장시간 들을 때는 화면이 꺼지지
않도록 설정해두세요.

**Q. 파일 접근 권한을 요청하는데 왜 필요한가요?**
A. ROM/사운드폰트/MIDI 파일을 `Download` 폴더에서 읽어야 하기 때문입니다.
Android 11+ 에서는 "모든 파일 접근" 권한을 허용해야 합니다.

## 7. 저작권 관련 안내

- SC-55/MT-32/88emu ROM은 Roland Corp.의 저작물이며 이 앱에는 포함되어 있지
  않습니다. 본인이 소유한 정품 기기에서 추출하는 등 합법적인 경로로만 구해서
  사용하세요.
- S-MU2000 ROM은 YAMAHA Corp.의 저작물이며 마찬가지로 포함되어 있지 않습니다.
- SF2 사운드폰트는 각 제작자의 라이선스를 따릅니다.
- 88emu 코어(`dsp56300/gearmulator`)는 **GPL-3.0**입니다. S-MU2000 코어는
  BSD-3-Clause이지만 MAME 프로젝트에서 유래한 부분(SH-2/SWP30 에뮬레이션)을
  포함하고 있어 **MAME License(비상업적 사용만 가능) 조건도 함께 적용될 수
  있습니다**. 개인적으로 빌드해서 쓰는 데는 문제가 없지만, 앱을 배포(스토어
  업로드, APK 공유 등)할 계획이 있다면 각 조건을 다시 확인하세요 — 자세한
  내용은 [README의 "라이선스/크레딧"](../README.md#라이선스--크레딧)을
  참고하세요.
